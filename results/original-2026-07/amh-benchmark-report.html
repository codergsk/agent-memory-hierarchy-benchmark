Executive Summary

What this benchmark proves: The Agent Memory Hierarchy (AMH) reduces input token consumption by selecting only MRDF-scored relevant memories, while simultaneously improving personalization and keyword recall vs all three traditional baselines. The naive vector store (Gen3) accumulates unbounded memories, increasing retrieval noise over time. The conversation buffer (Gen2) loses cross-session context entirely. AMH is the only approach that improves on all three axes simultaneously: cost ↓, quality ↑, personalization ↑.
